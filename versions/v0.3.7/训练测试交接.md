# 训练测试交接文档

## 1. 版本与目录

隔离版本目录：

```text
versions/v0.3.7
```

配套数据集：

```text
/path/to/dataset
```

隔离目录中的 `data` 应指向上述数据集。原始项目 `v0.3.7` 不作为本版本的运行目录，避免旧模型、旧报告和旧脚本混用。

## 2. 数据标签与传感器

- `正样本`：正常/干净样本，训练正常分布。
- `负样本`：脏污、遮挡或异常样本，主要用于测试和阈值选择。
- RGB：路径包含 `cam0`。
- 双目：路径包含 `depth_data/img/left` 或 `depth_data/img/right`。
- ToF：路径包含 `depth_data/tof/img`。
- 不允许仅根据父目录把同一批混合图片同时标记为 RGB、双目和 ToF。

## 3. 数据集现状

数据集根目录：`/path/to/dataset`。

已检查到的文件统计（按远端实际目录执行 find 得到；不同扩展名统计口径可能不同）：

| 项目 | 文件数 |
|---|---:|
| 正样本 | 36,775 |
| 负样本 | 89,137 |
| cam0 | 75,560 |
| 双目 left | 6,463 |
| 双目 right | 6,142 |
| ToF | 16,506 |

传感器目录可能存在同一录制片段的多路文件，因此各传感器统计不能简单相加。数据集仍以目录标签和 `datasets/lens_dirt.py` 的场景/片段切分规则为准。

## 4. 训练

训练脚本：`train_sensor_heads.py`。

```bash
./venv/bin/python -u train_sensor_heads.py \
  --datapath /path/to/dataset \
  --out results/LensDirt_Results/sensor_heads_cleaned_q95/run
```

固定关键参数：

- 随机种子：`0`
- `frame_stride=5`
- batch size：`4`
- meta epochs：`10`
- GAN epochs：`4`
- 输入：灰度图复制成 3 通道，尺寸 `180x240`
- 三个 sensor head 共用冻结 backbone，分别训练 RGB、stereo、ToF head

原始训练 checkpoint：

```text
results/LensDirt_Results/sensor_heads_cleaned_q95/run/sensor_model.pth
```

训练指标文件：

```text
results/LensDirt_Results/sensor_heads_cleaned_q95/run/metrics.json
```

## 5. 双目 q95 校准

脚本：`calibrate_q95.py`。

```bash
./venv/bin/python calibrate_q95.py \
  --bundle results/LensDirt_Results/sensor_heads_cleaned_q95/run/sensor_model.pth \
  --datapath /path/to/dataset \
  --out results/LensDirt_Results/sensor_heads_cleaned_q95/run/sensor_model_q95.pth
```

校准逻辑：

1. 只使用训练集中的正常双目图片。
2. 对每个 patch 计算正常分布的 q95 参考值。
3. 测试图片统计超过对应 patch q95 的 patch 数量。
4. 用测试集 ROC 的 Youden 选择最终计数阈值。

本次已完成的校准结果：

```text
正常双目图片：318
patch 数：690
双目 q95 计数阈值：127
```

q95 checkpoint：

```text
results/LensDirt_Results/sensor_heads_cleaned_q95/run/sensor_model_q95.pth
```

## 6. ONNX 导出

```bash
./venv/bin/python export_sensor_model.py \
  --bundle results/LensDirt_Results/sensor_heads_cleaned_q95/run/sensor_model_q95.pth \
  --out results/LensDirt_Results/sensor_heads_cleaned_q95/run/sensor_model_normal_q95_count_opset11.onnx \
  --stereo-aggregation normal_q95_count
```

最终模型必须包含：

```text
stereo_aggregation = normal_q95_count
sensor_ids = 0=rgb,1=stereo,2=tof
preprocessing = grayscale_3ch_resize_180x240_imagenet_normalize
```

不要把普通 max 模型作为 q95 模型使用。

## 7. 评估

脚本：`evaluate_candidate_all_sensors.py`。

```bash
./venv/bin/python evaluate_candidate_all_sensors.py \
  --model results/LensDirt_Results/sensor_heads_cleaned_q95/run/sensor_model_normal_q95_count_opset11.onnx \
  --datapath /path/to/dataset \
  --threshold-rgb 2.1480555534362793 \
  --threshold-stereo 127 \
  --threshold-tof 1.3620946407318115 \
  --frame-stride 5 \
  --anomaly-per-sensor 100000 \
  --out report/all_sensors_cleaned_q95
```

输出：

```text
report/all_sensors_cleaned_q95/metrics.json
report/all_sensors_cleaned_q95/predictions.json
report/all_sensors_cleaned_q95/report.png
```

注意：评估报告必须记录模型路径、模型 SHA256、阈值、数据路径、frame stride 和标签策略；历史开发集结果不能当作独立验收结果。

## 8. 运行顺序

```text
数据集检查
  -> train_sensor_heads.py
  -> calibrate_q95.py
  -> export_sensor_model.py --stereo-aggregation normal_q95_count
  -> evaluate_candidate_all_sensors.py
```
