# SimpleNet 镜头脏污检测 —— 测试报告

> 生成日期：2026-09-17
> 本报告只陈述有数据/文件支撑的客观事实，未做主观推断。

---

## 一、任务与方案

| 项目 | 说明 |
|---|---|
| 任务 | 判断镜头画面是否「脏污 / 被遮挡」（场景级二分类，不定位位置） |
| 方法 | SimpleNet（无监督异常检测，CVPR 2023） |
| 训练方式 | 仅用正常样本（正样本）训练，测试时用正常 + 脏污样本评估 |
| 输入 | 仅 RGB（cam0 相机），忽略双目 / tof / 深度 |

---

## 二、数据构成（按录制片段切分，无泄漏）

| 划分 | 数量 | 说明 |
|---|---|---|
| 训练集（正常） | 500 张 | 25 个录制片段 |
| 测试集（正常） | 240 张 | 12 个录制片段（与训练零重叠） |
| 测试集（脏污） | 1674 张 | 84 个录制片段 |

- 去冗余：每个录制片段均匀抽 20 帧（原始 76,436 张 → 约 2,414 张有效）。
- 训练/测试按「录制片段」切分（7:3），避免同片段既训练又测试导致的指标虚高。

## 六、误检分析（客观统计）

## 七、结论

1. 当前模型在无数据泄漏的客观测试下，**图像级 AUROC ≈ 0.74**，整体可区分正常/脏污，但尚未达到工业可用水平。
2. 误检的**最显著客观规律是光照**：极端光照（光照不良/强光/关灯）下误检率高达 35% ~ 50%，正常光照下仅 0% ~ 15%。
3. 脏污类型中「遮挡」类漏检最明显（38.6%）。

以下仅为可选方向，未做主观断言，需进一步用数据验证：
